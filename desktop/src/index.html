Account recovery

Reset password or change security mode?

Church Cap will stop its local server, remove the stored operator password, sign out existing operator sessions, restart, and open account setup. You will create a new password there and can keep or change the current security mode.

What does the security mode change?

The security mode controls where the operator controls can be reached. It does not remove language resources, models, captions settings, or other Church Cap data.

  • Secure operator mode — recommended: audience captions remain available on the local network, while operator controls are intended for the Church Cap computer.
  • Easy offline mode: audience captions and operator controls are available on the local network. This is convenient for testing, but less isolated.
  • Managed-device HTTPS mode: intended for church-owned devices where a local certificate authority has already been installed and trusted.

Your Church Cap settings are kept

Only the operator sign-in credentials are reset. Language resources, application settings and other Church Cap data remain in place.

This cannot be undone. Even if you only want to change the security mode, you will need to create a new operator password before signing in again.

Factory reset

Erase Church Cap's local data?

Church Cap will stop its local server, erase its local operator account and configuration, restart, and open the complete first-time setup.

This will remove

  • Operator credentials and every Church Cap setting.
  • Saved transcripts, service measurements, logs and files exported inside Church Cap's application-data folder.
  • Downloaded caption-translation and spoken-audio models. They will need to be downloaded again if selected during setup.

This cannot be undone. The installed Church Cap application is kept, but its local data is not.
