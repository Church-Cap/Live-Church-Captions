Add captions to OBS

Church Cap provides a transparent local caption overlay for OBS browser sources. It uses the same caption feed as phones and display screens, so no separate plugin or cloud service is required.

OBS

Recommended OBS settings

First open Operator → Congregation → OBS Live Stream, choose the required output language, and copy the generated URL. Every URL identifies one language and ends with parameters similar to ?integration=obs&lang=en.

  1. In OBS, click Sources → + → Browser and name the source Church Cap captions.
  2. Paste the complete language-specific URL copied from Church Cap.
  3. Set width to 1920 and height to 300 for a lower-third layout, then place the source near the bottom of the stream canvas.
  4. Enable Refresh browser when scene becomes active if you want OBS to reconnect automatically when switching scenes.
  5. Start Church Cap captions and check the source shows the selected language.

Changing the language on the Operator page creates a new address. Copy it into OBS and refresh the existing browser source. Church Cap intentionally shows only the direct-IP option because it is the clearest choice between computers on the church network.

Operating notes

The overlay has a transparent background and shows the current caption with the same smoother caption pacing used by the audience display. If the overlay is blank, confirm captions are running, the presentation computer can reach the generated URL, and no firewall is blocking the Church Cap port.

For public livestreams, remember that AI captions and translations can be inaccurate. They may also include spoken names, pastoral details, testimony, or copyrighted worship lyrics. Use blank/pause mode when captions should not be shown or retained.

Open-source support note

Church Cap is open-source local software. It is provided under its open-source licence without warranty. Test the overlay before the service, and make sure your church's privacy, safeguarding, accessibility, and copyright practices are followed.
