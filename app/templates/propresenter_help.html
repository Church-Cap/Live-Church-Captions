Add captions to ProPresenter

Church Cap's transparent local caption overlay can be placed in a ProPresenter Prop as a Web object. It uses the same caption feed as phones and display screens, so no separate plugin or cloud service is required.

ProPresenter

Add captions with a Prop

First open Operator → Congregation → ProPresenter, choose the required language, and copy the complete URL shown there. Every URL identifies one language and looks similar to /propresenter?lang=en. Props created with an older /obs?integration=propresenter&lang=… address keep working.

Each Prop has one fixed language. Create another Prop when two audience outputs need different languages.

  1. Open Show Controls → Props, select + to create a Prop, then right-click it and choose Edit.
  2. In the Prop editor, click the globe icon. Click and drag near the bottom of the canvas to create a wide Web object.
  3. Paste the generated address into the Web object's URL field on the right and press Enter. “Waiting for captions” means it is ready.
  4. Open Screens → Edit Looks. Enable the Props layer for the required Audience screen, then make that Look live.
  5. Click Show in the bottom-right of the Prop editor, or trigger the Prop thumbnail from the main window. Start captions in Church Cap and speak; clear the Prop when captions should be hidden.
Remember: enabling the Props layer and showing the Prop are separate actions. Enabling the layer only permits Props to appear; you must also click Show or trigger the Prop. Because the overlay is transparent, it can look empty when no caption is active.

The Operator page reports when a ProPresenter Web object is connected. A translated Prop requests its selected translation while it is open, but it is not counted as a congregation viewer. Props are drawn over a Video Input, making this suitable for captions over an incoming programme feed. Rehearse the Web object for a full service-length session and confirm the chosen Look sends Props only to the intended Audience screen. If the Web object is unreliable on the church's system, composite the video and Church Cap overlay in OBS and send that result to ProPresenter as a Video Input.

Operating notes

The overlay has a transparent background and shows the current caption with the same smoother caption pacing used by the audience display. If the Prop is blank, confirm captions are running, the ProPresenter computer can reach the generated URL, and no firewall is blocking the Church Cap port.

AI captions and translations can be inaccurate. They may also include spoken names, pastoral details, testimony, or copyrighted worship lyrics. Use blank/pause mode when captions should not be shown or retained.
