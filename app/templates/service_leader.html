Improve caption health

  • Ask the operator to move the Performance slider toward Fast or Fastest.
  • Use Faster Whisper and a smaller model when delay matters more than maximum accuracy.
  • Run the 15-second benchmark on the operator page during normal speech.
  • Reduce the number of active translated languages.
  • Use a direct sound-desk feed and close other demanding programs.
  • For regular live use, aim for a recent 6–8 core CPU and 16 GB RAM, or supported GPU acceleration.
