Open-source and local processing details

The Broad pack uses SMaLL-100 with CTranslate2, plus OPUS-MT for Tigrinya. The PyTorch pack uses the original SMaLL-100 model and only claims NVIDIA acceleration when the installed PyTorch runtime reports CUDA is available. Software and model licences are documented with Church Cap; live translation runs locally after the selected pack is downloaded.

Network operator access · Caution

Convenient, but less isolated

Operator controls can be reached from other devices on the same LAN. A password is still required, but exposing sign-in increases the security risk.

Advantage

Trusted operators can control Church Cap from another computer or tablet.

Disadvantage

Every device on that LAN can reach operator sign-in. Use only a trusted private network.

Language packs · Local and optional

Which packs should I install?

Start with Broad unless you have a specific compatibility reason. Installing both uses more storage, but Automatic mode still tries the efficient provider first.

Both · Automatic

Installs the packs one at a time, then lets Church Cap try the best available local provider in a safe fallback order.

Extra installed packs increase download time and storage. Simultaneous viewer languages—not the number of installed packs—usually have the greatest effect on live translation workload.
